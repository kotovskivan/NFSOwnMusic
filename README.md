# NFS Own Music

Your own songs in **Need for Speed** (PC) — free, open-source tools that add your music as new tracks next to the game's soundtrack.
Fan-made by **Kitivski + Claude** (Claude — AI by Anthropic). Not affiliated with Electronic Arts.

**Website:** https://kotovskivan.github.io/NFSOwnMusic/ (14 languages)

| Game | Tool | Status |
|---|---|---|
| Need for Speed Unbound (2022) | [Unbound Soundtrack](https://github.com/kotovskivan/UnboundSoundtrack) · [website](https://kotovskivan.github.io/UnboundSoundtrack/) · [NFSMods](https://nfsmods.xyz/mod/8161) · [Nexus Mods](https://www.nexusmods.com/needforspeedunbound/mods/671) | available |
| Need for Speed Heat (2019) | [Heat Soundtrack](https://github.com/kotovskivan/HeatSoundtrack) · [website](https://kotovskivan.github.io/HeatSoundtrack/) | coming soon |
| the rest of the series | — | waiting |

## This repository

The website source. The built site lives in the `gh-pages` branch.

| File | What |
|---|---|
| `shablon.html` | layout and style, one for all languages |
| `teksty/*.txt` | texts, one file per language (`key = text`) |
| `sajt.txt` | links, tool versions, languages, site address |
| `igry.txt` | every PC Need for Speed: year, title, status |
| `sobrat.py` | builder → `gotovo/` (`--prosmotr` to preview, `--opublikovat` to publish) |
